# 编码器485输出

当前SENSORLESS_CANOPEN_BUILD默认启用的VOFA输出使用UART0（PA00/PA01，PA09控制DE）。当前候选固件配置为 **2500000 baud、8N1、无流控、JustFloat**；每10ms最多一帧，32字节，7个float通道。2.5 Mbps接收链路仍待烧录后实测。

| 通道 | 数据 |
|---|---|
| CH0 | 电机编码器单圈原始计数，0～131071 |
| CH1 | 输出编码器单圈原始计数，0～524287 |
| CH2 | 电机端单圈角度，度 |
| CH3 | 输出端单圈角度，度 |
| CH4 | 数据有效标志 |
| CH5 | 实际使能标志 |
| CH6 | 输出帧序号，0～65535循环 |

无效位置通道发送NaN；数据尾为`00 00 80 7F`。串口仅输出观测数据，接收字节丢弃；该构建不通过此口执行HarmoCore控制/升级命令。

主循环一次有界FIFO写入，不阻塞等待发送，不在PWM中断中打印。提高波特率缩短线上发送时间；输出频率与每帧CPU工作量不变。编码器自身采集UART及1ms采集周期与本打印通道独立。

对应候选固件、哈希和验证：[2.5 Mbps发布报告](../../diagnostics/vofa_2m5_20260919/RESULT.md)。此前115200的历史发布包不适用这一接收配置；板上是否已更新需核验实际固件。
